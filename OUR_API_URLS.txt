--- if departments works but the rest fails, check this ---

1) Base URL must be https://hospitalq-webapp.vercel.app — not localhost from openapi unless you run our server locally.

2) Queue paths need a department from GET /api/departments:
   - Best: copy data[]._id (24-character hex)
   - Also works: slug such as general-opd, dental, pediatrics
   - Wrong: example ids from the yaml (64f1a2b3...) — those are placeholders, not our live DB

3) Login before check-in or overview:
   POST /api/auth/login  body {"email":"reception@hospitalq.com","password":"password123"}
   Header on locked routes: Authorization: Bearer PASTE_data.token

4) POST /api/queue body must be JSON with at least:
   {"patientName":"Artisan name","department":"PASTE_dept_id_or_slug"}

5) First request after idle may return 503 DB_NOT_CONNECTED — wait 2–3 seconds and retry (serverless cold start).

6) All paths include /api/ — e.g. /api/queue not /queue

7) Windows curl: broken JSON on login is common — use /docs Try it out, Postman, or fetch/axios with JSON.stringify.
